## 모순 정의 (물리적 모순)
드론 프로펠러 가드의 개구(開口) 상태는 두 이유 때문에 상반된 값을 가져야 한다.
- 손가락이 날개에 닿지 않게 하려면 가드가 닫혀 있어야 한다.
- 공기가 자유롭게 통과하게 하려면 가드가 열려 있어야 한다.

(사용자가 모순 문장을 확인했다. 그래서 다시 묻지 않고 진행했다.)

## 분리 유형
`data/separation-principles.json`의 질문으로 각 유형을 판단했다. 입력에 답이 없는 축은 입력에서 추정했다.

| 유형 | 닫힘이 필요한 경우 | 열림이 필요한 경우 | 판단 |
| --- | --- | --- | --- |
| 관계(조건)에 의한 분리 | 손가락(굵은 고체)에 대해 | 공기(유체)에 대해 | 겹치지 않음 → 선택 (1순위) |
| 시스템 수준에 의한 분리 | 가드 전체 면이 손가락을 막음 | 개별 개구 하나하나는 공기를 통과시킴 | 겹치지 않음 → 선택 (2순위) |
| 공간에 의한 분리 | 가드 표면 전체 | 가드 표면 전체 | 같은 면에 두 요구가 함께 걸림 → 제외 |
| 시간에 의한 분리 | 취급할 때 | 비행할 때 | 비행 중에도 손이 닿을 수 있어 완전히 분리되지 않음 → 제외 |
| 방향에 의한 분리 | 손가락은 반경 방향에서 접근 | 공기는 축 방향으로 흐름 | 방향이 일부 다르다. 그러나 두 요구가 같은 개구를 지나므로 제외 |

## 적용 아이디어
### 원리 #3 국소적 품질 (관계: 손가락 대 공기)
적용한 하위 원리: "균일한 구조를 부분마다 다른 구조로 바꾼다", "대상의 각 부분이 서로 다른 기능을 맡게 한다".
- 아이디어 1: 균일한 격자 대신 개구 크기를 위치별로 바꾼다. 날개 끝 쪽 외곽 링은 개구를 손가락이 들어갈 수 없는 크기(예: 지름 약 8 mm 이하)로 만든다. 허브 근처는 공기 흡입량이 크므로 개구를 크게 두되 깊이를 늘려 손가락 도달 거리를 막는다. 이 설계는 "손가락에는 닫힘, 공기에는 열림"을 구현한다.
- 아이디어 2: 가드 둘레에 이중 기능 구조를 둔다. 바깥 링은 충돌을 흡수하고, 안쪽 살은 손가락 차단과 공기 유도를 맡는다. (사례: `mechanical`의 표면만 굳힌 기어는 부분별 역할 분담을 보여 준다.)

### 원리 #1 분할 (시스템 수준)
적용한 하위 원리: "나누는 정도를 더 높여 조각을 더 잘게 한다".
- 아이디어 1: 가드를 하나의 큰 구멍 대신 수백 개의 작은 육각 셀로 나눈다. 셀 하나는 손가락보다 작아서 닫힌 상태와 같다. 셀이 많아서 전체 개방 면적은 크다. 부품 수준은 "닫힘", 전체 수준은 "열림"이다.
- 아이디어 2: 셀 벽을 얇고 길게 만든다. 이렇게 하면 공기 저항이 작고, 셀 깊이가 손가락 접근을 막는다.

### 원리 #17 다른 차원으로
적용한 하위 원리: "한 줄 배열 대신 여러 층으로 쌓거나 2·3차원으로 움직이게 한다", "대상을 기울이거나 옆으로 눕힌다".
- 아이디어 1: 평면 격자 대신 3차원 덕트형 가드를 쓴다. 프로펠러를 짧은 덕트(원통)가 감싸고, 덕트 입구에 얕은 그물을 둔다. 덕트 벽이 옆에서 오는 손가락을 막는다. 공기는 축 방향으로 자유롭게 지난다.
- 아이디어 2: 살을 기류 방향으로 기울여 눕힌다(루버형). 정면에서는 공기가 통과한다. 옆에서 접근하는 손가락은 살에 막힌다.

### 원리 #5 통합 (시스템 수준)
적용한 하위 원리: "같거나 비슷한 대상을 공간적으로 가깝게 합친다".
- 아이디어 1: 프로펠러 가드와 기체 프레임의 팔을 한 몸으로 합친다. 가드가 구조재 역할도 하므로, 별도 가드를 덧붙일 때보다 살 수를 줄여 개방 면적을 키울 수 있다.
- 아이디어 2: 인접한 프로펠러 둘을 하나의 가드로 감싼다. 가드 외곽 길이가 줄어 차단 구조 때문에 막히는 공기 단면이 줄어든다.

### 원리 #19 주기적 조치
적용한 하위 원리: "연속적인 작용을 주기적인 펄스 작용으로 바꾼다".
- 아이디어 1: 이 원리는 시간 분리가 아니라 관계 목록에서 나왔다. 그래서 보조 아이디어로만 쓴다. 착륙 후 취급 단계에서만 프로펠러 정지 신호와 연동한 셔터형 덮개를 닫는다. 비행 중에는 열어 둔다. 단, 비행 중 손가락 접근은 이 방식으로 막을 수 없다. 그 위험은 #3, #1, #17의 구조가 맡는다.
